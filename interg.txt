### 🗺️ L'Architecture Globale de ton code

Pour que ton projet reste propre, modulaire et facile à maintenir (normes MVC/DevOps), l'intégration est découpée en 3 couches distinctes :
1. **La Couche Service (`services/phenix_scans.py`) :** Le client HTTP asynchrone qui centralise toutes les requêtes brutes vers `api.phenix-scans.co`, gère le verrou de concurrence (`Semaphore`) contre les erreurs 429, et formate les dictionnaires de données.
2. **La Couche Contrôleur (Dossier `routes/`) :** Tes fichiers de routes FastAPI (`home.py`, `manga.py`, `reader.py` et `search.py`) qui gèrent la mise en cache SQLite (`cache.get_or_set`), le blindage de sécurité active (`Self-Healing`), et injectent les données dans les pages.
3. **La Couche Vue (Dossier `templates/`) :** Tes fichiers HTML qui affichent proprement les données (avec chargement progressif des images en HD).

### 🛠️ ÉTAPE 1 : Créer le Client d'API (`services/phenix_scans.py`)

Crée un nouveau fichier appelé **`services/phenix_scans.py`**. Ce client va faire office de traducteur entre les serveurs de Phenix Scans et ton application MangaNoka.

#### 1. Structure de base & Types :
```python
from __future__ import annotations
import logging
import asyncio
from typing import TypedDict
from datetime import datetime, timezone
import httpx

logger = logging.getLogger(__name__)

BASE_API_URL = "https://api.phenix-scans.co/api"
BASE_UPLOADS_URL = "https://api.phenix-scans.co"
TIMEOUT = 30.0

class ChapterDict(TypedDict):
    number: str
    title: str
    url: str
    date: str

class MangaDict(TypedDict):

    slug: str
    cover: str
    type: str

    status: str
    rating: float
    genres: list[str]
```

#### 2. L'accueil parallélisé et résilient (`get_latest_mangas`) :
Puisque la liste globale `/manga` ne renvoie pas de chapitres, nous devons interroger les chapitres pour chaque manga. Pour éviter de saturer leur pare-feu (erreur `429`), on utilise un **`asyncio.Semaphore(2)`** et un **stagger (décalage) de 100ms** combinés à une boucle de retries asynchrone :
```python
class PhenixScansAPI:
    def __init__(self):
        self.client = httpx.AsyncClient(timeout=TIMEOUT)
    
    async def close(self):
        await self.client.aclose()

    async def get_latest_mangas(self, page: int = 1, limit: int = 12) -> tuple[list[MangaDict], int]:
        try:
            response = await self.client.get(f"{BASE_API_URL}/manga", params={"page": page, "limit": limit})
            response.raise_for_status()
            data = response.json().get("data", [])
            
            # Semaphore à 2 pour lisser les requêtes parallèles
            sem = asyncio.Semaphore(2)
            
            async def fetch_chapters_for_manga(item):
                async with sem:
                    manga_id = item.get("id", "")
                    slug = item.get("slug", "")
                    chapters = []
                    if manga_id:
                        await asyncio.sleep(0.1) # Petit décalage de 100ms
                        
                        retries, backoff = 3, 0.5
                        for attempt in range(retries):
                            try:
                                chapters_response = await self.client.get(f"{BASE_API_URL}/manga/{manga_id}/chapters")
                                if chapters_response.status_code == 429:
                                    await asyncio.sleep(backoff)
                                    backoff *= 2.0
                                    continue
                                    
                                chapters_response.raise_for_status()
                                chapters_data = chapters_response.json().get("data", [])
                                
                                # Tri décroissant des numéros de chapitres
                                chapters_data.sort(key=lambda x: float(x.get("number", 0)), reverse=True)
                                
                                for ch in chapters_data[:3]: # Top 3 derniers chapitres
                                    ch_num = str(ch.get("number", "1")).rstrip(".0")
                                    chapters.append({
                                        "number": ch_num,
                                        "title": f"Chapitre {ch_num}",
                                        "url": f"/read/{slug}/{ch_num}",
                                        "date": self._format_date(ch.get("createdAt", ""))
                                    })
                                break # Succès, on sort des retries
                            except Exception:
                                if attempt == retries - 1:
                                    logger.warning(f"Failed to fetch homepage chapters for manga ID {manga_id}")
                return chapters

            tasks = [fetch_chapters_for_manga(item) for item in data]
            chapters_lists = await asyncio.gather(*tasks, return_exceptions=True)
            
            mangas = []
            for idx, item in enumerate(data):
                chapters = chapters_lists[idx] if not isinstance(chapters_lists[idx], Exception) else []
                mangas.append({
                    "title": item.get("title", ""),
                    "slug": item.get("slug", ""),
                    "cover": f"{BASE_UPLOADS_URL}/{item.get('coverImage', '')}",
                    "type": item.get("type", "Manhwa"),
                    "synopsis": item.get("synopsis", ""),
                    "author": "Inconnu",
                    "status": item.get("status", "Ongoing"),
                    "rating": float(item.get("averageRating", 0.0) or 0.0),
                    "genres": [g["name"] for g in item.get("genres", [])],
                    "chapters": chapters,
                    "chapter": chapters[0] if chapters else {"number": "", "title": "", "url": "", "date": ""}
                })
            return mangas, 1
        except Exception as exc:
            logger.error(f"Error fetching latest mangas: {exc}")
            return [], 1
```

#### 3. Récupérer les Détails d'un Manga (`get_manga_detail`) :

```python
    async def get_manga_detail(self, slug: str) -> MangaDict | None:

                    for ch in chapters_data:

                        chapters.append({

                            "title": f"Chapitre {ch_num}",
                            "url": f"/read/{slug}/{ch_num}",

                    chapters.sort(key=lambda x: float(x["number"]), reverse=True)

                    logger.error(f"Failed to fetch chapters for manga ID {manga_id}: {ch_exc}")

            return {
                "title": data.get("title", ""),
                "slug": data.get("slug", ""),
                "cover": f"{BASE_UPLOADS_URL}/{data.get('coverImage', '')}",
                "type": data.get("type", "Manhwa"),
                "synopsis": data.get("synopsis", ""),
                "author": "Inconnu",
                "status": data.get("status", "Ongoing"),
                "rating": float(data.get("averageRating", 0.0) or 0.0),
                "genres": [g["name"] for g in data.get("genres", [])],
                "chapters": chapters,
                "chapter": chapters[0] if chapters else {"number": "", "title": "", "url": "", "date": ""}
            }
        except Exception as exc:
            logger.error(f"Error fetching manga {slug}: {exc}")
            return None
```

#### 2. Fiche Manga (`routes/manga.py`) :
Ajoute la fonction d'**Auto-Correction active (Self-Healing)**. Si le cache a stocké un objet `None` corrompu, le serveur le détecte, le re-scrape en direct et l'écrase proprement en base pour s'auto-réparer silencieusement sans crash 500 :
```python
    api = get_phenix_api()
    try:
        manga = await cache.get_or_set(
            f"manga:fr:{slug}",
            MANGA_TTL_SECONDS,
            lambda: api.get_manga_detail(slug),
        )
        
        # SÉCURITÉ ACTIVE : Si l'entrée de cache est None, on la re-scrape et la répare en direct !
        if not manga or not isinstance(manga, dict) or not manga.get("title"):
            manga = await api.get_manga_detail(slug)
            await cache.get_or_set(f"manga:fr:{slug}", MANGA_TTL_SECONDS, lambda: manga)
            
        if not manga or not manga.get("title"):
            raise HTTPException(status_code=404, detail="Manga non trouvé")
```

### 🎨 ÉTAPE 3 : Ajuster ton Lecteur d'Images (`templates/reader.html`)

Puisque nous récupérons les liens d'images absolus directement depuis leur serveur CDN d'images ultra-rapide, nous n'avons pas besoin de faire du proxying S3.

Ouvre ton fichier **`templates/reader.html`** et remplace la boucle de rendu d'images :
* *Avant :* `data-src="/{{ slug }}/{{ chapter }}/{{ loop.index }}.webp"`
* *Après :* `data-src="{{ image }}"`
